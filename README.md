# Тактичка онлайн

Публичный учёт фигур, отрядов, ресурсов и боёв тактички «Сериала»:
https://sairaila-cmd.github.io/taktichka-live/

- Смотреть может каждый по ссылке; правки — по личному коду персонажа (раздаёт ведущий).
- Всё, что меняется, записывается в журнал: кто, когда и что.
- Помощник боя ведёт очередь фигур по фазам (Условия → Сила → Риск → Ущерб), считает Силу,
  бросает d10 и показывает исход; оба игрока видят бой вживую.

## Как устроено

| Что | Где |
|---|---|
| Страница | `index.html`, `css/`, `js/` — статический сайт для GitHub Pages, без сборки |
| Расчёт боя | `js/battle.js` — чистая функция, проверяется `tests/test_battle.py` |
| База | Supabase: схема и правила — `supabase/schema.sql`, проверки — `supabase/test_schema.py` |
| Справочник свойств | `supabase/properties.json` (таблица «Пять ликов одной Луны», вкладка «Свойства фигур») |
| Начальные данные | `tools/make_seed.py` → `supabase/seed.sql` (из дашборда «Фигуры тактички») |
| Изменения базы после запуска | `supabase/migrations/` — выполнить в SQL Editor по порядку |

Читать базу может любой (ключ в `js/config.js` публичный); писать — только через функции `api_*`,
которые проверяют личный код. Сами коды в репозитории и в базе не хранятся — только их отпечатки (sha256).
Supabase ограничивает размер ответа; для полных справочников интерфейс загружает результаты страницами,
чтобы крупные таблицы и история не обрезались на лимите одного запроса.
Справочники в браузере загружаются один раз за сессию страницы; изменяемые данные игроков можно обновить
отдельно, не запрашивая повторно свойства и номиналы.

## Проверки

```
python supabase/test_schema.py supabase/schema.sql   # база на локальном Postgres (pip install pgserver psycopg2-binary)
python tests/test_battle.py                          # расчёт боя (pip install mini-racer)
python tests/ui_mock.py                              # страницы игры и боя в Chromium на подставных данных (pip install playwright)
python tests/smoke.py                                # все разделы против живой базы, только чтение
```
